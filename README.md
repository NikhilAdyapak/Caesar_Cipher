# Caesar Cipher

A Caesar cipher program in C that encodes and decodes text by shifting letters. Built in my second semester (2019-2020) as a C project.

## Files

```
Encrypt.c     encode a message
Decrypt.c     decode a message
Main.c        driver program
functions.h   shared helpers
Makefile.mk   build file
```

## Build and run

```bash
make -f Makefile.mk
./Main
```

Input text is read from `input.txt` and results are written to `output.txt`.
